# reserve

## Logo

Files live in `assets/logo/`:

- `logo.svg`: full logo for light backgrounds
- `logo-dark.svg`: full logo for dark backgrounds
- `logo-mark.svg`: the icon on its own
- `favicon.svg`: the browser-tab icon

The wordmark is converted to vector outlines, so it doesn't need a web font.
Open `assets/logo/preview.html` to see every version.

```html
<link rel="icon" href="/assets/logo/favicon.svg" type="image/svg+xml">
<img src="/assets/logo/logo.svg" alt="reserve" height="40">
```
